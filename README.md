# myco-lab

Pilzzucht-Labor: Protokolle, Kulturführung, Messdaten.

Systemübersicht:

- Kulturweg: Slant-Bank -> Agarplatte -> Kornbeutel -> Monotub
- Sterilisation: Presto 01781 (Dampf, Kornbeutel), AME24 (Wasserbad, Substratgläser)
- Inkubation: Kibernetik KS240L mit Inkbird ITC-308, Sollwert 23 °C
- Archiv: Minikühlschrank 4-8 °C (Slants), Tiefkühler -18 °C (Glycerin-Bank)
- Klima-Logging: SwitchBot Thermo-Hygrometer IP65 + Hub Mini, CSV-Export
